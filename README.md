# FocusNest Pomodoro
A responsive focus timer that runs locally in your browser.

## Features
- 25-minute focus and 5-minute short-break modes
- Start, pause, and reset controls
- Completed focus-session counter
- Optional browser notifications
- No frameworks, server, account, or external dependencies

## Run
Open `index.html` in a modern browser.

## Privacy
The timer runs locally and does not send data to a server.
